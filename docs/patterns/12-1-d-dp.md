# 12 · 1-D Dynamic Programming — House Robber

- **Visualizer id:** `house-robber` · **Folder:** `visualizers/house-robber/`
- **Title:** "House Robber"
- **Story:** at each house there are only two choices: skip it and keep the best so far, or take it plus the best from two houses back. Write each answer down once.

## Input
- `inputLabel`: `nums =` · `inputMaxLength`: 30
- `inputHint`: `1–8 amounts from 0 to 99, one per house, separated by spaces.`
- Presets and expected answers:
  - `2 7 9 3 1` → `12` (houses 1, 3 and 5)
  - `1 2 3 1` → `4` (houses 1 and 3)
  - `2 1 1 2` → `4` (houses 1 and 4)

## Reference solution
```ts
function rob(nums: number[]): number {
  const dp: number[] = new Array(nums.length + 1).fill(0);
  dp[1] = nums[0];
  for (let i = 2; i <= nums.length; i++) {
    const skip = dp[i - 1];
    const take = dp[i - 2] + nums[i - 1];
    dp[i] = Math.max(skip, take);
  }
  return dp[nums.length];
}
```
`dp[i]` is the most you can take from the first `i` houses.

## Steps
| Moment | lines | note (example) |
|---|---|---|
| setup | 1 | dp[i] is the most you can take from the first i houses. With none, it’s 0. |
| base | 2 | With one house, take it: dp[1] = 2. |
| compare | 3, 4, 5 | House 3 has 9. Skip it: keep 7. Take it: 2 + 9 = 11. |
| decide | 6 | Taking wins. dp[3] = 11. |
| done | 8 | Done. The best haul is 12, from houses 1, 3 and 5. |

For the `done` note, reconstruct which houses were robbed by walking dp back from the end (taking wins when `dp[i] !== dp[i-1]`).
`sr` example: `House 3 of 5, amount 9. Skip gives 7, take gives 11. dp so far: 0, 2, 7, 11.`
State: `{ nums, dp: (number | null)[], i, skip, take, choice: "skip" | "take" | null, robbed: number[] | null }`.

## View
- **Houses row:** each house is a cell with a small roof (a CSS triangle with a 2px `--line` border) and the amount inside. The current house is orange and lifted.
  At `done`, robbed houses become `found` (mint) with a `✓ robbed` label under them.
- **dp row** aligned under the houses, with an extra leading cell for `dp[0]` (so dp[i] sits under house i). Filled cells are card with the value.
  The cell being decided is `range` (tint-yellow) until `decide` fills it.
- **Two arrows** into the cell being decided: from `dp[i-1]` tagged `skip` (inverse) and from `dp[i-2]` tagged `take +9` (lilac).
  On `decide`, the winning arrow goes solid 3px and the losing one dashed `--past-line`.
- **Stats:** `skip` · `take` · answer tile `best`.
