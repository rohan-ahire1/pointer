# 13 · 2-D Dynamic Programming — Longest Common Subsequence

- **Visualizer id:** `longest-common-subsequence` · **Folder:** `visualizers/lcs/`
- **Title:** "Longest Common Subsequence"
- **Story:** fill a table one cell at a time. Each cell only looks up, left, or diagonally up-left, and the corner holds the answer.

## Input
- `inputLabel`: `text1 text2 =` · `inputMaxLength`: 13
- `inputHint`: `Two words of 1–6 lowercase letters, separated by a space.`
- Presets and expected answers:
  - `abcde ace` → `3` (“ace”)
  - `abc abc` → `3` (“abc”)
  - `abc def` → `0`

## Reference solution
```ts
function lcs(a: string, b: string): number {
  const dp = Array.from({ length: a.length + 1 }, () =>
    new Array(b.length + 1).fill(0));
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      if (a[i - 1] === b[j - 1]) {
        dp[i][j] = dp[i - 1][j - 1] + 1;
      } else {
        dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
      }
    }
  }
  return dp[a.length][b.length];
}
```

## Steps (one per cell, plus 3)
| Moment | lines | note (example) |
|---|---|---|
| setup | 1, 2 | Make a table with a row of zeros on top and a column of zeros down the left. |
| match | 3, 4, 5, 6 | ‘c’ = ‘c’. Take the diagonal and add one: 2. |
| no match | 3, 4, 5, 8 | ‘b’ ≠ ‘c’. Carry the bigger of up (1) and left (1): 1. |
| trace back | 12 | Walk back from the corner through the matches to read the subsequence: “ace”. |
| done | 12 | Done. The longest common subsequence has length 3: “ace”. |

## Tests: brute force
Every subsequence of `a` (≤ 64) that is also a subsequence of `b`; take the longest length. Also check the traced-back string really is a common subsequence of that length.
